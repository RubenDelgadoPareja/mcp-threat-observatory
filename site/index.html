> Evidence, not verdicts

An observatory for the MCP supply chain. It records what a server advertises, what it does at runtime, and what changed between two reviews — and grades every claim as observed or inferred, with the blind spots attached.

# what changed since the last review
$ ... drift before.json after.json --fail-on-change

01 · passive

No code executed

A client handshake and nothing more: auth posture, tool metadata, schema strictness, discovery semantics, capability composition.

02 · behavioural

Isolated execution

The server runs with no network route, a temporary HOME and seven canary credentials. Every tool is invoked once with schema-generated arguments.

03 · drift

Change you can gate

Hashes the full tool definition, so a relaxed destructiveHint is caught even when no visible text changes.

Generated by the tool, not by hand

Nine synthetic fixtures, one per posture. No third-party server was contacted. Open any report to see exactly what the collector emits.

What this does not claim

No third-party server was contacted and no third-party package was executed for these reports. A finding is a signal for review, not a verdict about a publisher. Behavioural mode isolates the network only; filesystem containment is on the roadmap.
